# 🥋 Maratona Java - DevDojo

Repositório dedicado ao aprendizado de Java, acompanhando as aulas da **Maratona Java (POO e CORE)** do canal DevDojo. Aqui registro minha evolução, desde os tipos primitivos até as estruturas condicionais e muito mais!

---

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** Java 21+
* **IDE:** IntelliJ IDEA / VS Code
* **Versionamento:** Git & GitHub

---

## 📁 Estrutura do Projeto
O código está organizado por aulas para facilitar a consulta:

* `Aula01OlaMundo.java`: Primeiros passos com a linguagem.
* `Aula02TiposPrimitivos.java`: Estudo sobre variáveis e memória.
* `Aula04Operadores.java`: Operadores aritméticos, relacionais e lógicos.
* `Aula05Condicionais.java`: Estruturas de decisão (`if`, `else`, `!`).

---
