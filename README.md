Repositório dedicado ao armazenamento de códigos e exercícios práticos da **Maratona Java (POO e CORE)** do canal DevDojo. O objetivo é registrar toda a jornada de aprendizado, desde os fundamentos até conceitos avançados de Orientação a Objetos.

---

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** Java (JDK 17+)
* **IDE:** IntelliJ IDEA / VS Code
* **Versionamento:** Git & GitHub

---

## 📁 Organização do Repositório
Para manter a escalabilidade, o projeto está organizado dentro do pacote principal:
`src/devdojo/maratonajava/introducao/`

Os arquivos seguem o padrão de nomenclatura do curso:
* **AulaXX...**: Classes numeradas sequencialmente conforme o progresso nos tópicos de lógica, condicionais, estruturas de repetição, arrays e POO.
